# Парсер e-latts не видел акции с длинным названием

**Что случилось.** В первой версии парсера e-latts название товара я искал по `-oTitle" href=`. У длинных названий сайт ставит ссылке второй класс (`-oTitle -sLong`), и 4 акции из 438 отбрасывались как нечитаемые. Тесты на фикстуре были зелёными, потому что в ней не было ни одной такой плитки.

**Почему возникла.** Фикстуру я собрал по нескольким типичным плиткам, а не по всем вариантам разметки. Вариации классов у остальных полей я проверил только после живого прогона, когда число разобранных (434) не сошлось с числом плиток со старой ценой (438).

**Как исправлено.** Регулярные выражения для названия и ссылки принимают лишние классы (`-oTitle[^"]*"`), разделитель плиток тоже (`-oProduct[^"]*"`). Реальная плитка 15384 добавлена в фикстуру, тест на лишний класс и на длинное название. На живых данных 438 из 438.

**Как повлияло на остальной код.** Только `packages/scrapers/e-latts`. Ошибка найдена до коммита, в боевую БД не попала.

**Как не допустить.**
- Для парсера HTML сверять число плиток в источнике с числом принятых: расхождение значит, что формат разобран не весь, до того как цифра попадёт в отчёт.
- В фикстуру класть по плитке каждого варианта разметки (длинное название, депозит, нет цены за единицу), а не только типичные.
