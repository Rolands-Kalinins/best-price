# Apotheka (apotheka.lv) — разведка 2026-11-01 (реализовано в 2.4.0.0, вариант 3)

Группа: аптеки. Magento с React-интерфейсом, серверный рендер. Открывается обычным `fetch`. Браузерная разведка (Playwright) не делалась: профиль занят зависшим Chrome, вывод сделан по HTML и JS сайта.

## Правила
`robots.txt` закрывает `/catalog`, `/catalogsearch`, `/customer/ajax`, `/customer/rx`, `/checkout`, `/rest`, `/index.php`, `/productalert`, `/stockQuantity` и служебные. Разделы `/produkti/...?p=N`, страницы товаров в корне и sitemap не закрыты. `ajaxUrl` списка (`/catalog/ajax/listproduct/`) лежит под закрытым `/catalog`, поэтому им не пользуемся: данные те же есть в самом HTML.

## Находки
- Страница списка весит ≈0,64 МБ и отвечает ≈6,5 с (весь корень 182 страницы ≈ 20 минут при паузе 0,5 с). `?p=N` работает; `?page=` игнорируется.
- Поля товара в JSON списка: `id`, `sku` («PMM0015950LV»), `name`, `url`, `priceSimple` (число), `priceOld` (строка «6,70 €»), `discountPercent`, `price` (HTML-фрагмент с `<data value="…">`), `brand` (строка или `false`: у 6 002 из 6 175 есть), `activeSubstance` (2 634), `itemCategory` (4 569, например «šampūni šampūni pret izkrišanu»), `isMedicine` (639: гомеопатия и ОТС, не рецептурные), `image.image_url`, `actions.isSalable`. Штрихкода (GTIN) в списке нет.
- Скидка: в `price` есть `<del>` старая цена и `<ins><data value>` новая; `discountPercent > 0` у 1 597, старая цена выше текущей у 802 (расхождение объяснить не удалось: у остальных процент есть, а `<del>` нет; сверить на фикстуре). Срока скидки в данных не нашли.
- **Цена для зарегистрированных** («Cena reģistrētiem lietotājiem», иконка лояльности): отдельный `price-item special` с `<data value>`; у 954 из 6 175. Это аналог цены по карте (условие «для зарегистрированных пользователей»). Пример: 27,10 → 17,62 (−35%).
- В наличии (`isSalable`): 5 753 из 6 175, нет в наличии 422.
- **В списках нет 2 959 товаров из sitemap (9 133).** Выборка 30 из них (равномерно по sitemap): 18 «InStock», 12 «OutOfStock», у всех есть цена и GTIN. Состав: рецептурные препараты (проверена карточка омепразола: `@type ["Product","Drug"]`, `prescribingInfo` со ссылкой на zva.gov.lv, цена видна, в хлебных крошках только «Mājas») и обычные товары, которых нет в наличии (Tena, Blend-a-dent, Actifed). Точную долю рецептурных не измеряли (признак рецептурности по тексту страницы ненадёжен: слово «recepšu» есть в шаблоне любой карточки), надёжный признак — `@type` с `Drug`.
- Все 6 175 с ценой, у списка нет товаров без цены.

## Что не проверено
Срок скидок и цены для зарегистрированных, GTIN у товаров из списка (нужны карточки), 429 и блокировка адресов GitHub, условия использования, полнота 2 959 вне списка (не знаем, сколько из них доступны к заказу).

## Варианты
1. **Только списки `/produkti?p=N`** (6 175, 182 запроса ≈ 117 МБ, ≈ 20 минут): цена, старая цена, цена для зарегистрированных, бренд, категория, наличие. Без штрихкода и без рецептурных.
2. **Списки плюс карточки рецептурных и штрихкодов** (≈2 959 + 6 175 карточек, ≈ 3 ГБ первый раз): полный охват с EAN. Дорого; карточку каждого товара можно брать один раз и хранить GTIN в БД, дальше обновлять только цену из списка.
3. **Списки плюс карточки из sitemap, которых нет в списке (≈ 2 959)**, оставляя только в наличии (по выборке ≈60%, ≈ 1 800 карточек, ≈ 700 МБ). Рецептурные получают флаг по `@type Drug`.

## Риски
Медленные ответы (≈6,5 с), долгий прогон (≈ 20 минут и больше), закрытый `/catalog` (мы его не трогаем), блокировка адресов GitHub не проверена.

## Реализовано (2.4.0.0)
Выбран вариант 3. Живой прогон 2026-11-01: 7 761 товар = 6 175 списка + 1 586 карточек в наличии (из ≈2 960 вне списков), 0 отброшено, 57 минут. Рецептурных 1 567, EAN 1 586, старая цена 603 (из 643 с `<del>`: часть равна текущей и отбрасывается схемой), цена для зарегистрированных 954, категория источника 4 568. Старая цена только из `<del>`: расхождение 1 597 и 802 объяснилось (954 из них цена для зарегистрированных без `<del>`). Карточка читается ≈0,3 с, но читать приходится все ≈2 960, чтобы узнать наличие. User-Agent бота принят и списком, и карточками.
