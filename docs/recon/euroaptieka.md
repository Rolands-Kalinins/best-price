# Euroaptieka (euroaptieka.lv) — разведка 2026-11-01, реализовано в 2.1.0.0

Группа: аптеки. Next.js (фронт) + бэкенд на `api.euroaptieka.lv`, Cloudflare. Открывается обычным `fetch` с честным User-Agent.

## Правила
`robots.txt`: `Allow: /`, закрыты `/checkout`, `/krepselis`, `/meklet/`, `/poisk/`, `/login`, `/register`, `/order`, `/cart/save`, `/payment`. Карточки `/p/...` и sitemap открыты. `api.euroaptieka.lv/api/*` отвечает 403 (закрыт намеренно), его не трогаем.

## Что оказалось (главное)
- **Страницы списков `/l/<категория>` рисует браузер**: в HTML заглушки (`react-loading-skeleton`) и только ссылки `/p/...` (48 на страницу), без цен. Данные приходят серверным действием Next.js (POST с `Next-Action`), это хрупко. `/l/akcijas` отдаёт 158 готовых плиток, но это только клубные скидки.
- **Карточка товара `/p/<slug>` самодостаточна.** В скрипте `self.__next_s.push([0, {type: "application/ld+json", children: "<json>", id: "product-schema"}])` лежат `Product` (`sku`, `name`, `brand.name`, `gtin13`, `offers.price` **в центах**, `availability`, `image`, `url`) и `BreadcrumbList` (путь категории). Вес ≈140 КБ со сжатием (850 КБ без), ≈0,5 с на запрос.
- Поэтому парсер берёт **все карточки из sitemap**, а не списки.

## Охват
- `sitemap/products.xml`: 13 213 адресов, **6 608 латышских** (остальные `/ru/p/...` дубли с теми же `sku`).
- Категории: `sitemap/taxons.xml`, 680 латышских; верхний уровень: `maminas-un-berni`, `medicinas-preces`, `bezrecepsu-medikamenti`, `uztura-bagatinataji-vitamini`, `higiena`, `adas-un-matu-kosmetika`, `mutes-higiena`, `davanas`.

## Что есть и чего нет
- Есть: артикул, название, бренд, **штрихкод `gtin13`**, обычная цена, наличие, картинка, путь категории.
- Нет: старой цены и срока акции. Цена по клубной карте (например −52% при покупке от 9 EUR) в карточке не лежит, это условная скидка; она видна только на плитках `/l/akcijas`. Рецептурный признак не найден (раздел называется «Bezrecepšu medikamenti», то есть безрецептурные).

## Варианты (выбран первый)
1. **Карточки из sitemap** (≈6 600 запросов, ≈0,9 ГБ, 3 потока с паузой): реализовано. Первая карточка сохраняется в `debug/` на случай смены формата.
2. Списки через серверное действие Next: быстрее, но привязано к внутреннему идентификатору действия, ломается при каждом релизе сайта.
3. Браузер (Playwright) по спискам: новая зависимость и браузер в CI, не берём.

## Риски
Cloudflare может заблокировать адреса GitHub (при 403 парсер падает сразу, без повторов; по решению владельца магазин тогда снимаем). Формат ld+json и обёртка `__next_s` могут измениться при релизе сайта: тогда доля непрочитанных карточек превысит 5% и запуск упадёт, а не запишет мусор. Клубные скидки не собираются (можно добавить из `/l/akcijas`).
