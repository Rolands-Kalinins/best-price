# Benu (benu.lv) — разведка 2026-11-01 (переписана при реализации 2.3.0.0)

Группа: аптеки. Первая разведка (HTML-списки `/e-aptieka?page=N`, «EAN нет») оказалась неполной: списки на самом деле рисует браузер из открытого поиска Luigi's Box, а в карточке товара есть встроенный JSON с `EANCode`.

## Правила
`robots.txt`: `Disallow: /*?vars`, `/*?search=`, `Allow: /v/`. Sitemap: `/sitemap.xml` (индекс: статьи, категории, страницы, `products/sitemap-1..14.xml`). Сам API на чужом домене (`live.luigisbox.com`); условия использования (ToS) не читались.

## Источник данных (его и парсим)
```
GET https://live.luigisbox.com/search?tracker_id=232949-269228&f[]=type:item&f[]=status:active&f[]=availability:1&sort=item_id:asc&size=200&page=N
```
- Без cookies и ключей (`tracker_id` вшит в HTML страниц). `size` не больше 200 (иначе 400). Окно результатов 10 000: `total_hits` выше не показывает.
- Ответ: `results.total_hits`, `results.hits[]` = `{ url, attributes }`; почти все поля массивы из одного элемента.
- **Сортировка по умолчанию нестабильна:** страницы пересекаются, при полном обходе 7% записей терялись (5 935 ответов = 5 502 уникальных). `sort=item_id:asc` даёт ровно `total_hits` уникальных (проверено: 6 070 из 6 070, 31 страница).
- Фильтры `f[]=поле:значение` работают (`status`, `availability`, `main_category_lvl_1`, `drugType`); список значений поля — `&facets=<поле>:100`.
- Сайт отвечает `429 Retry later` при частых запросах: пауза 0,7 с и повтор с ожиданием.

## Охват (на 2026-11-01)
- В индексе ≥16 тыс. записей: `active` 6 800 (в наличии 5 973 при потерянном обходе, 6 070 при стабильном), `new` 548, `hidden` 7 354. Рецептурные (`drugType = RX`, 1 418, раздел «Recepšu medikaments») все со статусом `new` и без наличия, поэтому в выборку «active в наличии» не попадают; флаг `prescription` разобран и покрыт тестом на копии такой записи.
- Выборка парсера: `status:active` + `availability:1` = **6 070** товаров, все с ценой; скидок 3 715 (в 3 715 есть период), EAN 6 007, картинка 6 070.
- Sitemap товаров (6 910) сверен: 6 798 есть в выгрузке по категориям, остальное потеряно из-за нестабильной сортировки, а не отсутствует в API.

## Поля записи
`item_id` (код), `titleRaw`, `brand`, `price_amount` / `price_old_amount` (числа), `classic_discount_date` («01.11. - 30.11.», без года), `ean` (бывает PZN и внутренние коды: «PZN-17444652», «-16563662»; штрихкод только 8–14 цифр), `category_upto_lvl_5` («Раздел|Подраздел|Группа»), `availability` («1»), `status`, `drugType` (`basic`, `OTC`, `RX`), `image_link`, `original_url`.
- Цена по карте: `hasLCPrice = 1`, `loyal_customer_price_amount`, период `benu_card_discount_date` (тот же формат). Среди продаваемых товаров её нет (81 запись по всему индексу, все скрытые и не в наличии); парсер поддерживает на будущее.
- Условная цена «в корзине от 9.99 €» (из первой разведки) в этих данных не видна и не собирается.

## Риски
Чужой поисковый сервис (формат может измениться; тогда парсер упадёт по проверкам формата и полноты), `tracker_id` может смениться (он в HTML сайта), 429 при частых запросах, блокировка адресов GitHub с Benu не проверялась до слияния.
