## Общие выводы

1. **Для сравнения цен нужен весь каталог, а не только акции.** В `docs/PLAN.md` сказано «Берём только акции», это решение для продуктов. «Самая дешёвая цена одного товара» в аптеках и косметике требует цен на всё, иначе сравнивать нечего. Это изменение архитектуры, решает владелец (вопрос 1 ниже).
2. **Ключ сопоставления: EAN, где он есть.** Drogas, Euroaptieka, Apotheka (со страницы товара), возможно Douglas дают штрихкод. У Mēness и Benu его нет: сопоставление по бренду, размеру и словам названия (существующий `packages/core/src/match.ts`) плюс, возможно, Gemini. У аптек много позиций с формой/дозой/числом таблеток («N20»), ключ товара придётся расширять.
3. **Рецептурные лекарства не берём.** У Mēness есть атрибут `receipt`; остальные сайты рецептурное не продают онлайн или отдельно. Обязательно отсекать (юридически и по смыслу).
4. **Нагрузка.** Полный обход: Drogas 96 запросов (≈35 МБ), Mēness 103 (≈390 МБ, 100 товаров на запрос), Benu ≈290, Euroaptieka ≈140+ (по 48 на страницу), Apotheka ≈290 списков + до 9 100 карточек ради `gtin`, Douglas ≈142 (по 100). Запросы редкие, с паузой, ночью.
5. **CI.** Cloudflare/Akamai могут блокировать адреса GitHub (как было с e-LaTS, см. `docs/PLAN.md`). Из Actions ничего из этого не проверялось. Запасной вариант для каждого: запуск с ПК (FR-31).

## Порядок реализации (рекомендация)

1. **Mēness aptieka**: чистый JSON, акции с датами, нет защиты. Самый дешёвый старт для аптечного раздела, заодно проверяем схему `pharmacy.*`.
2. **Drogas**: JSON, EAN у всех, но сначала решение по robots (вопрос 2).
3. **Euroaptieka**: HTML + JSON-LD с `gtin13`.
4. **Benu**: простой HTML, без EAN.
5. **Douglas**: HTML, 14 тыс. товаров, EAN под вопросом.
6. **Apotheka**: самый тяжёлый (EAN только на странице товара).

## Решения владельца (2026-11-01)

1. Берём **весь каталог**, не только акции.
2. **Drogas отложен** (спорный `robots.txt`, см. выше); файл `drogas.md` остаётся на будущее. Остальные магазины идут в работу: у них в `robots.txt` каталог не закрыт. Условия использования (ToS) сайтов не читались.
3. Схемы `pharmacy.*` и `cosmetics.*` одобрены. В косметике пока остаётся один Douglas.

## Что нужно было решить (закрыто выше, пункты 1–3; пункт 4 про Mēness остаётся в силе: берём `e-menessaptieka.lv`)

1. Берём **весь каталог** (рекомендую для аптек и косметики) или только акции, как для продуктов?
2. **Drogas**: `robots.txt` на `www.drogas.lv` содержит `Disallow: /api/v2/` и запрет на `*?query=`, `*&currentPage=`. API живёт на другом хосте (`api.drogas.lv`, его robots недоступен: Akamai отвечает Access Denied), и работает без cookies. Правило «не обходить запреты» (`site-recon`): использовать этот API или идти через страницы в настоящем браузере (тяжело и медленно) или пропустить Drogas?
3. Структура: схемы `pharmacy.*` и `cosmetics.*` (по образцу `grocery.*`) и разделы в меню: согласны?
4. Mēness: сайт `menessaptieka.lv` из задания это корпоративный сайт без цен, магазин на `e-menessaptieka.lv`. Берём магазин, верно?
