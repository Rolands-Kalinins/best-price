# Журнал версий

Формат версии `А.Б.В.Г` и правила повышения: раздел «Версия приложения» в `CLAUDE.md`. Заметки релиза на GitHub берутся из раздела нужной версии.

## 1.2.0.1 — 2026-10-28
- Локальная БД для разработки: Supabase в Docker (`pnpm db:start`/`db:reset`/`db:stop`/`db:status`), чтобы не работать на боевой базе. Сид заводит тестового админа `dev@bestprice.local`; в `pnpm dev` на `/login` появляется вход по паролю (в боевой сборке его нет). Теперь страницы можно проверять в браузере без Google OAuth.

## 1.2.0.0 — 2026-10-28
- Парсер Etop (1402 акции): `POST /v1/Products/GetPromotionProducts` страницами по 500 (прежний план с `GetCarousel` давал только 27 товаров). Типы: обычная акция, цена по карте top! (условие «Ar top! karti», обычная цена как старая), TIP TOP, ZG. EAN, категория и даты у всех. Цену за кг/л считаем из названия: серверная не сходится у 223 товаров. Каталога без акций у Etop нет. Job `etop` в GitHub Actions; на `main` ещё не запускался.

## 1.1.2.0 — 2026-10-27
- Исправлен парсер Rimi: единичный таймаут запроса ронял весь запуск в GitHub Actions. Теперь до трёх попыток с паузой для сетевых ошибок и 5xx/429.

## 1.1.1.0 — 2026-10-27
- Исправлен парсер Maxima: `limit=1000` перестал вмещать все акции (стало 1136), запуск в GitHub Actions падал на проверке полноты. Теперь `limit=5000`, проверка полноты осталась.
- Исправлена сборка сайта: на Vercel в боевую сборку попал устаревший CSS (белая тема вместо нашей). Отключён постоянный кэш сборки Turbopack, в CI добавлена проверка CSS собранного сайта.

## 1.1.0.0 — 2026-10-27
- Парсер Rimi (≈4000 акций): три прохода списка, период действия с карточки товара, категория (код `SH-…`), цена по карте MansRimi, условия «N un vairāk» и «Ja liec grozā N». Job `rimi` в GitHub Actions.
- Страница акций отбирает данные на сервере: фильтры, поиск и сортировка в адресе, «Показать ещё» по 60 (потолок 1000). Миграция `offers_scale`: столбцы `discount` и `search`, быстрые политики доступа.
- Акции без даты окончания показываются, только пока товар виден в запусках последние 3 дня (FR-34).
- Защита парсеров: дубли товаров, старая цена не выше новой, ссылки только на свой сайт.
- Конвейер релиза: CI на каждый PR, проверка миграций и версии, тег и заметки релиза после слияния, проверка деплоя Vercel. Журнал ошибок `docs/findings/`.

## 1.0.0.0 — 2026-10-25
